ＣＧテーブルの設定

ＣＧテーブル の設定をします。

設定ファイル

// *************************************************************
// ■ＣＧテーブルの設定
// =============================================================
#CGTABLE_FILE = "mode.cgm"
#CGTABLE_FLAG_CNT = 1000
#CGTABLE_FILE

ＣＧテーブルのファイル名を指定します。

#GLOBAL_FLAG.CNT

ＣＧテーブルのフラグの個数を指定します。
