シェイクの設定

シェイク の設定を行います。

設定ファイル

// *************************************************************
// ■シェイクの設定
// =============================================================
#SHAKE.CNT = 4         // シェイクの個数
#SHAKE.000 = (0,8,64)(0,-8,64)(0,8,64)(0,-8,48)(0,8,32)
#SHAKE.001 = (-32,32,64)(-32,-32,64)(32,-32,64)(32,32,64)(16,-16,64)(-8,-8,64)(-4,4,48)(2,2,32)
#SHAKE.CNT

シェイクの個数を設定します。

#SHAKE.??? = ([x], [y], [time])...

揺れをコマ単位で設定します。 各コマの揺れＸ、Ｙ、かける時間を指定します。
