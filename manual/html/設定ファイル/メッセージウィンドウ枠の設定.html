メッセージウィンドウ枠の設定

メッセージウィンドウ枠の設定をします。

各メッセージウィンドウ枠個別の設定については メッセージウィンドウ枠個別の設定 を参照して下さい。

設定ファイル

// *************************************************************
// ■メッセージウィンドウ枠の設定
// =============================================================
#WAKU.CNT = 32          // 枠の個数
#WAKU.BTN.CNT = 20      // ボタンの個数
#WAKU.FACE.CNT = 1      // 顔グラフィックの個数
#WAKU.OBJECT.CNT = 1    // オブジェクトの個数
#WAKU.CNT

メッセージウィンドウ枠の個数を指定します。

#WAKU.BTN.CNT

枠の持つボタンの個数を指定します。

#WAKU.FACE.CNT

枠の持つ顔グラの個数を指定します。

#WAKU.OBJECT.CNT

枠の持つ子オブジェクトの個数を指定します。
