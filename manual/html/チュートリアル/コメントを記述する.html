コメント

シーン内にコメントを記述できます。 コメントはゲームには影響しません。 スクリプトを分かりやすくするために記述して下さい。

//行コメント
/* ～ */ブロックコメント

コメントの例

ここはコメントではありません。 // ここはコメントです。
/* 
ここはコメントです。
 */

上のスクリプトで、緑色の部分はコメントとなり、無視されます。 

/*
ここはコメントではありません。 /* ここはコメントです。 */
ここはコメントではありません。（コメントは入れ子にはできない）
 */

ブロックコメントは入れ子にはできません。 上の例は、最後の */ の部分でコンパイルエラーになります。
