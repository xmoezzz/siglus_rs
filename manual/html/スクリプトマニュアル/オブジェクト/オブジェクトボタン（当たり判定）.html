オブジェクトボタン（当たり判定）

透明な部分は当たらないようにする

画像のうち、透明な部分を当たり判定から除き、画像の見た目通りの当たり判定にします。 

front.object[0].set_button_alpha_test(1)       // 機能を有効にする
front.object[0].set_button_alpha_test(0)       // 機能を解除する
a[0] = front.object[0].get_button_alpha_test   // 値を取得する
