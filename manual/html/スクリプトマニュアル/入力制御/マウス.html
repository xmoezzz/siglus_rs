マウス

マウスの情報を取得します。

マウスの持つキー

mouse.left
mouse.right

マウスのキー情報を使うことは滅多にありません。 通常は、「決定キー」「キャンセルキー」などを使います。 詳しくは 決定キーとキャンセルキー を参照して下さい。

マウスの位置を取得する

a[0] = mouse.get_pos_x     // Ｘ座標を取得
a[1] = mouse.get_pos_y     // Ｙ座標を取得
mouse.get_pos($x, $y)      // 一度に取得
mouse.pos_x、mouse.pos_y でも座標を取得できます。
サンプル：マウスの座標を取得する
mouse.get_pos(a[0], a[1])

マウスの位置を設定する

mouse.set_pos($x, $y)      // 一度に設定

メニューを出したときに、メニューの先頭に自動的にマウスを動かしたい場合があると思います。 そのときに使って下さい。 ただし、自動で移動するのを好まないユーザもいます。 メニューを閉じたときに元の位置に戻す、もしくは 自動で動かす機能を ON/OFF できる、などの配慮が必要かも知れません。

ホイールの値を取得する

a[0] = mouse.wheel

マウスのホイールの回転数を取得するコマンドです。（マイナス=上方向、プラス=下方向）

ホイールの値を取得するには、キーと同様、clear や next と組み合わせて使う必要があります。 

mouse.clear
while (1)  {

    if (mouse.wheel > 0)  {
        // ホイールを下方向に回したときの処理
    }
    if (mouse.wheel < 0)  {
        // ホイールを上方向に回したときの処理
    }

    mouse.next
    disp
}

マウスの状態のみをクリアする

mouse.clear

マウスの状態のみをクリアします。通常は input.clear を使います。

マウスの状態のみを更新する

mouse.next

マウスの状態のみを更新します。通常は input.next を使います。
