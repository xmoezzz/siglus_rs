ユーザコマンドを作る

_start.ss
#z00

$hello                // コマンド $hello を呼び出します。

owari                 // ゲームを終了します。

command $hello        // ここから、コマンド $hello の中身です。
{
    こんにちは。r
}

こんにちは。

command { } を使ってコマンドを作ります。 コマンドを呼び出す場合は、通常のコマンドと同じように、コマンドの名前を書くだけです。
