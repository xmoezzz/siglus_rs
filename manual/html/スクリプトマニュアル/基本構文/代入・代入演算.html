スクリプトマニュアル　＞　基本構文　＞　代入・代入演算

代入

代入は "=" を使います。 

a[0] = 10        // a[0] に 10 を代入する
a[0] = 30 + 5    // a[0] に 30 + 5 の結果を代入する

文字列も整数と同じように、文字列フラグに代入できます。 

s[0] = "abc"     // s[0] に "abc" を代入する

代入演算

代入と演算を同時に行えます。 

a[0] += 5           // a[0] = a[0] + 5 と同じ
a[0] *= 10 + a[1]   // a[0] = a[0] * (10 + a[1]) と同じ
s[0] += "def"       // s[0] = s[0] + "def" と同じ
代入演算子一覧
a[0] += 整数加算代入（足し算）
a[0] -= 整数減算代入（引き算）
a[0] *= 整数乗算代入（掛け算）
a[0] /= 整数除算代入（割り算）
a[0] %= 整数剰余算代入（余り）
a[0] &= 整数AND 演算代入（論理積）
a[0] |= 整数OR 演算代入（論理和）
a[0] ^= 整数XOR 演算代入（排他的論理和）
a[0] <<= 整数左シフト演算代入
a[0] >>= 整数右シフト演算代入（算術）
a[0] >>>= 整数右シフト演算代入（論理）
s[0] += 文字列加算代入（足し算）
s[0] *= 整数乗算代入（掛け算）
