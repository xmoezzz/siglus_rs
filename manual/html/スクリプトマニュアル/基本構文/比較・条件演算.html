条件演算

等号・不等号

整数 == 整数左と右が等しい
整数 != 整数左と右が等しくない
整数 >= 整数右より左が大きいか等しい
整数 <= 整数右より左が小さいか等しい
整数 > 整数右より左が大きい
整数 < 整数右より左が小さい
文字列 == 文字列左と右が等しい
文字列 != 文字列左と右が等しくない
例
// a[0] が 0 の時に文字列を表示するサンプル
if (a[0] == 0) {
    print("こんにちは。")r
}

// a[0] が 5 より等しい時に文字列を表示するサンプル
if (a[0] >= 5) {
    print("こんばんは。")r
}

文字列の比較は、大文字小文字を無視して比較します。 

s[0] = "abc"
if (s[0] == "ABC") {
    /* ... */              // ここを通る
}

条件演算

A && BA と B が両方成り立つ
A || BA と B の片方、または両方が成り立つ
// a[0] が 0、かつ b[0] が 0 の時に文字列を表示するサンプル
if (a[0] == 0 && b[0] == 0) {

print("こんにちは。")r
}


// a[0] と b[0] のどちらか片方、または両方が 95 以上のときに文字列を表示するサンプル
if (a[0] >= 95 || b[0] >= 95) {

print("合格です！")r
}
