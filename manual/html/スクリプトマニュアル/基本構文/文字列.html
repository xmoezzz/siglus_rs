文字列

文字列は ""（ダブルクォート）で囲みます。 全角文字のみの場合は "" を省略できます。

表記意味
"abc"abc
"あいうえお"あいうえお
あいうえおあいうえお
"\\"\（円記号）
"\"""（ダブルコーテーション）
"'"'（シングルコーテーション）
" " （半角スペース）

文字列の例外

コマンドの引数や代入文の右辺としてのみ、半角文字列も文字列として扱います。 

front.object[0].create("BG001", 1, 0, 0)
front.object[0].create(BG001, 1, 0, 0)     // これでもＯＫ

危険な処理ですが、手間を考えると圧倒的に楽になります。 また、声撮りに関してもこの方が都合が良いです。
