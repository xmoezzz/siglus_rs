定義ファイルでユーザフラグを作る

定義ファイルでユーザフラグを作る

定義ファイル
#property   $point : int
#property   $name : str

名前の後ろに ": 型名" をつけ、フラグの型を指定します。

_start.ss
#z00

// $name に名前を、$point に好感度を代入する
$name = "舞"
$point = 5

// 好感度を１あげる
$point += 1

// 結果を表示する
print($name)の好感度が１あがった！r
現在の好感度はprint($point)です。r

// ゲームを終了する
owari
実行結果
舞の好感度が１あがった！
現在の好感度＝6

型名を省略する

#property   $point

型名を省略した場合は int 型（整数）になります。
