ラベルとラベルジャンプ

#label / goto

#label
goto #label

ラベルを作成することで、その場所にジャンプすることができます。

_start.ss
#z00

ここからスタートします。r
                            //
goto #label_01              // ─┐
                            //   │
ここは実行されません。r     //   │  ラベルまでジャンプする
                            //   │
#label_01                   // ←┘
                            //
ここが実行されます。r

owari
実行結果
ここからスタートします。
ここが実行されます。

Ｚラベルとシーンジャンプ

jump

jump($scene_name)
jump($scene_name, $z_label_no)

jump を使うことで、別のシーンにジャンプすることができます。 正確には、シーンの #z00 がある位置にジャンプします。

_start.ss
#z00

ここからスタートします。r

jump("５月１４日")
５月１４日.ss
#z00

次にここが実行されます。r

owari

Ｚラベル

Ｚラベルを使うと、シーンの途中にジャンプすることができます。 Ｚラベルは、#z00 ～ #z999 の合計1000個作ることができます。

(2012/04/13) 使えるZラベルが999まで増えました。今までは99まででした。
５月１４日.ss
#z00

jump("５月１５日", 01)       // ５月１５日.ss の #z01 にジャンプします。
５月１５日.ss
#z00

ここは実行されません。r

#z01

最後にここが実行されます。r

owari
