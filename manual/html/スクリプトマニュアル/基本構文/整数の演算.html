整数の演算

a[0] = a[0] + 10                  // 好感度を１０あげる
a[1] *= 2                         // 攻撃力を２倍にする
a[2] = ((b[0] * 2) - b[1]) / 4    // ダメージを計算する

基本演算

整数 + 整数加算（足し算）
整数 - 整数減算（引き算）
整数 * 整数乗算（掛け算）
整数 / 整数除算（割り算）
整数 % 整数剰余算（余り）
例
print(10 + 3)r
print(10 - 3)r
print(10 * 3)r
print(10 / 3)r
print(10 % 3)r
実行結果
13       // 10＋3 = 13
7        // 10－3 = 7
30       // 10×3 = 30
3        // 10÷3 = 3（余りは切り捨て）
1        // 10÷3 の余りは 1

演算はつなげることもできます。"()" を使うこともできます。 

a[0] = ((b[0] * 2) - b[1]) / 4    // ドラクエ風のダメージを計算する

論理演算

上級者向けの演算です。普通は使わないと思います。ビット演算が分かる方は使って下さい。

~ 整数NOT 演算（論理否定）
整数 & 整数AND 演算（論理積）
整数 | 整数OR 演算（論理和）
整数 ^ 整数XOR 演算（排他的論理和）
整数 << 整数左シフト演算
整数 >> 整数右シフト演算（算術）
整数 >>> 整数右シフト演算（論理）

通常の整数フラグでシフト演算を行った場合、左シフトは論理シフト、右シフトは算術シフトになります。 ビットフラグ の場合は負の数がないので、右シフトも論理シフトになります。

「>>>」を使った場合は、強制的に論理シフトになります。 

a[0] = 0b11011111111111111111111111111111
a[1] = a[0] << 2
print(a[0])

a[1] は 0b01111111111111111111111111111100 となります。
