メッセージにルビをつける

ruby($str)       // ルビを開始する
ruby             // ルビを終了する

ruby($str) と ruby で囲まれた文章にルビをつけます。

ルビの例
ruby("ぶんしょう") 文章 ruby に ruby("るび") ルビ ruby をつける ruby("てすと") テスト ruby です。
注意点

改行をまたぐ文章には、ルビをつけることができません。 上手く調整してください。

置換を使った例

定義ファイルの置換を使うと便利です。

定義ファイル
#define    @鈴    ruby("りん") 鈴 ruby
#define    @理樹  ruby("りき") 理樹 ruby
