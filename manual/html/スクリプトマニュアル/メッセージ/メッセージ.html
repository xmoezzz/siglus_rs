メッセージ

一般的なメッセージの例

koe(100000000,000)set_face(FCRN00)【鈴】「今日はすごいぞ」r
koe(100000001,000)set_face(FCRN01)【鈴】「聞いて驚け」r
koe(100000002,000)set_face(FCRN02)【鈴】「じゃん！」r

通常は、声、顔グラフィック、名前、メッセージ、r コマンドの順に並べます。

メッセージを表示する

print($num)
print($str)

メッセージを表示します。 フラグの内容を表示するときなどに使います。 

print(a[0])           // a[0] の値を表示する
print(a[0] + a[1])    // a[0] + a[1] の値を表示する

メッセージを消去する

clear

文字を消去する準備を行います。

実際は、すぐには消去されません。 次に文字が表示される直前に消去されます。 

（キャラ１を表示）
（文章１を表示）pp clear
wipe(0, 1000)
（キャラ２を表示）
（文章２を表示）pp clear

上記のような演出時、は、以下の用に処理されます。

  • キャラ１が表示される
  • 文章１が表示される
  • ワイプされる
  • キャラ２が表示される
  • 文章１が消える
  • 文章２が表示される

メッセージの表示終了を待つ

wait_msg

現在の文章が最後まで表示されるのを待ちます。 通常は自動で待つので、あまり使うことのないコマンドです。

メッセージのキー待ちを行う

pp

現在の文章が最後まで表示されるのを待ち、その後、キー待ちを行います。

メッセージのＲ待ちを行う

r

現在の文章が最後まで表示されるのを待ち、キー待ちを行い、メッセージのクリア準備を行います。 pp clear とほぼ同じコマンドです。 ほぼ全ての文章の後につけることになると思います。非常に重要なコマンドです。

ノベルモード の場合は、メッセージはクリアされません。 

【鈴】「今日はすごいぞ」r
【鈴】「聞いて驚け」r
【鈴】「じゃん！」r

メッセージのＲ待ちを行い、改ページする

page

ノベルモード で使います。 ノベルモードでは r コマンドでメッセージはクリアされないので、 ページの切り替え位置で page コマンドを使って下さい。
