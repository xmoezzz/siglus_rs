選択肢ポイント

選択肢ポイントとは？

選択肢ポイントは、「前の選択肢に戻る」で戻るスクリプトの位置です。

選択肢ポイントを設定する

selpoint

現在のセーブポイントの位置に選択肢ポイントを設定します。 選択肢ポイントは sel コマンドなどで自動的に設定されるので、 このコマンドを使う機会はあまりありません。 どんな時に使うかと言いますと、自力で選択肢などを作る時に使います。

selpoint は、「現在のセーブポイントの位置」に選択肢ポイントを設定するコマンドです。 selpoint コマンドを入れる位置は注意が必要です。 

// 選択肢の前にセーブポイントを置きます。
// 「前の選択肢に戻る」を使った場合、ここに戻ってきます。
savepoint

// まだ selpoint を置いてはいけません。
// 選択中に「前の選択肢に戻る」を選んだ場合、戻るべき位置は「１つ前の選択肢」です。
// ここに selpoint を置くと、ここに戻ってきてしまいます。

//
// ここに自分で作った選択肢を入れます
//

// selpoint を使うタイミングは、「選択終了後」のここです。
selpoint

// メッセージを表示します。
選択を終了します。r

選択肢ポイントをクリアする

clear_selpoint

選択肢ポイントが立っているかを判定する

a[0] = check_selpoint

0=立っていない、1=立っている
