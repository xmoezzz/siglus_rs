定義ファイル　＞　置換

置換

置換を使ってフラグなどに名前をつけると、スクリプトの見た目が分かりやすくなります。

例えば、主人公の体力、賢さ、運のよさ、など多くのフラグが必要だとします。 それぞれ a[0]、a[1]、a[2]… のようにフラグを割り当てますが、 そのままスクリプトに記述した場合、見通しが悪いです。

見通しの悪いスクリプトの例

a[0] += 5
a[1] += 3
a[2] += 7

そこで、定義ファイルを使って、フラグに名前をつけます。

定義ファイル
#define     @体力                  a[0]
#define     @賢さ                  a[1]
#define     @運のよさ              a[2]
見通しの良くなったスクリプトの例
@体力 += 5
@賢さ += 3
@運のよさ += 7

置換の先頭には、必ず @ をつけてください。

置換（define / replace）

文字列の置換を行います。

定義ファイル
#define     @好感度                a[0]
シーン０１.ss
@好感度 += 1
シーン０１.ss（置換後）
a[0] = 1

多重展開

define による置換は、多重展開されます。

定義ファイル
#define     @持ち物先頭            100
#define     @持ち物１              s[@持ち物先頭 + 0]
#define     @持ち物２              s[@持ち物先頭 + 1]
#define     @持ち物３              s[@持ち物先頭 + 2]
置換の流れ
@持ち物１ = "やくそう"
↓
s[@好感度先頭 + 0] = "やくそう"
↓
s[100 + 0] = "やくそう"

多重展開のよる無限ループ

以下のような置換は失敗します。 

#define     月宮            ruby(月宮) つきみや ruby
置換の流れ
月宮
↓
ruby(月宮) つきみや ruby
↓
ruby(ruby(月宮) つきみや ruby) つきみや ruby
↓
（…以下、無限ループ）

置換の先頭に @ をつけていれば問題ありませんが、どうしてもつけたくない場合もあります。 その場合は replace を使ってください。replace は多重展開されない置換です。

定義ファイル
#replace     月宮            ruby(月宮) つきみや ruby
置換の流れ
月宮
↓
ruby(月宮) つきみや ruby
